WEBSITE THƯ TÌNH - HƯỚNG DẪN NHANH

1. Mở index.html để xem thử trên máy tính.
2. Thay ảnh:
   - Chép ảnh của bạn vào thư mục images.
   - Đặt tên ảnh: anh-1.jpg, anh-2.jpg, ... anh-6.jpg
   - Nếu ảnh là PNG, hãy sửa đuôi tên trong mảng memories ở cuối index.html.
   - Sửa caption để viết lời nhắn riêng cho từng ảnh.
3. Sửa nội dung thư:
   - Tìm đoạn có id="letterBody" trong index.html và thay bằng lời nhắn của bạn.
   - Sửa [Tên của bạn] thành tên muốn ký.
4. Nhạc nền (không bắt buộc):
   - Chép file MP3 vào thư mục audio.
   - Trong index.html, tìm dòng source đang nằm giữa <!-- -->.
   - Bỏ dấu comment và sửa tên file cho đúng.

ĐĂNG LÊN GITHUB PAGES
1. Đăng nhập GitHub, tạo repository mới (ví dụ: thu-tinh).
2. Upload index.html, thư mục images và audio (nếu dùng).
3. Vào Settings > Pages.
4. Ở Build and deployment, chọn Deploy from a branch.
5. Chọn branch main, folder /(root), rồi Save.
6. Đợi GitHub tạo đường link website trong mục Pages.

LƯU Ý:
- Ảnh phải được upload vào repository cùng website thì người nhận mới xem được.
- Không dùng ảnh có quyền riêng tư hoặc ảnh của người khác khi chưa được phép.
- Nếu repository để Public, bất kỳ ai có link đều có thể xem nội dung và ảnh.
